# Aniimo Polska Hub

IMPORTANT VISUAL REFERENCES:

I have attached screenshots of the official Aniimo website.

Use these screenshots as the PRIMARY visual reference for the design language of this landing page.

Carefully study and recreate the overall visual feeling:

- layout proportions

- typography style

- navigation appearance

- rounded pill-shaped buttons

- cyan/blue accents

- subtle pink highlights

- thin decorative UI lines

- small futuristic interface decorations

- spacing and positioning

- full-screen background presentation

- the way UI elements float directly over the game artwork

- soft glow, blur and transparency effects

I want visitors to immediately feel that this website belongs to the Aniimo ecosystem.

However, do NOT make a pixel-for-pixel copy of the official website and do not reproduce its exact navigation or content. This is an independent, unofficial Polish community website called "Aniimo Polska".

The screenshots are STYLE REFERENCES, not content that should simply be placed on the page as images.

The final website should use the same overall design language while presenting original Aniimo Polska content.
